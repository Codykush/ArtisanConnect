# ArtisanConnect

ArtisanConnect is a responsive web platform designed to connect local roadside artisans with customers by providing them with digital visibility and an interactive marketplace experience.

This project focuses on authentication, structured database management, and dynamic user interaction using modern web technologies.

---

## 🚀 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **Firebase Authentication**
- **Firebase Firestore (NoSQL Database)**
- **MySQL (Relational Database – used in extended backend project)**

---

## ✨ Key Features

- 🔐 Secure User Registration & Login (Firebase Authentication)
- 📦 Real-time Product Data Management (Firestore)
- 📱 Fully Responsive UI Design
- 🔄 Structured Frontend–Database Integration
- ✅ Input Validation and Secure Data Handling

---

## 🧠 Project Objectives

- Provide digital presence to small-scale artisans
- Implement secure authentication workflows
- Manage structured and real-time database systems
- Build scalable and maintainable frontend architecture

## 🛠️ How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Codykush/ArtisanConnect.git
   ```

2. Open the project folder in VS Code

3. Configure Firebase (if needed)

4. Open `index.html` in your browser

---

## 🔐 Important Note

For security reasons, API keys and sensitive credentials should not be exposed in public repositories.  
Use environment variables or restricted Firebase rules in production environments.
